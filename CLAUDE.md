# Mi-downloads

Static Jekyll site (`theme: jekyll-theme-slate`) for GitHub Pages: a Persian resume/download page. Content is RTL Persian; keep `dir="rtl"` and the Vazir font.

- Edit `index.html`, `README.md`, `assets/custom.css`. Do not read `assets/*.css` vendor files (bulma) or images.
- No build or tests; preview by opening `index.html`.
